Architecture: Decoupled JavaScript / TypeScript Full-Stack

Product Requirements Document (PRD)

Frontline & Blue-Collar LMS — Pure JavaScript / TypeScript Architecture

Document Version: 1.1.0 Backend: Node.js + Express (TypeScript) Frontend: Next.js 14+ PWA + Admin Portal Database: Prisma ORM (SQLite / PostgreSQL)

1. Project Directory & File Structure

The system is organized into a clean decoupled structure where the Frontend and Backend are separate directories sharing unified TypeScript types:

LMS/

2. Frontend Pages Breakdown (Worker & Field Facing)

📱 FRONT-END PAGES: WORKER MOBILE PWA

Page F-1: Welcome & Zero-Email Authentication

/worker/login

Worker logs in via phone number + SMS/WhatsApp 4-digit OTP or by scanning their physical employee QR badge with their camera. Includes regional language audio selector.

Page F-2: Worker Home & Daily Shift Dashboard

/worker/dashboard

Displays today's required 2-minute safety bite, floating "Listen in My Language" text-to-speech button, and quick-action buttons for QR scanner and offline downloads.

Page F-3: Microlearning Video Player

/worker/learn/[id]

High-speed video stream with dual-language audio selector (switch voiceover without re-downloading video) and split-screen Wrong Way ❌ vs. Right Way ✔️ demos.

Page F-4: Interactive Visual Quiz

/worker/quiz/[id]

"Spot the Hazard" interactive tap canvas (tap 3 hazards on the worksite image) and swipe flashcard decision engine (Swipe right = Safe, Swipe left = Unsafe).

Page F-5: Machine Just-in-Time (JIT) QR Scanner

/worker/scan

Camera viewfinder scanning QR stickers on physical machinery to trigger a 45-second machine pre-operation SOP video on the spot.

Page F-6: My Skill Passport & Certifications

/worker/passport

Displays earned digital safety badges (Forklift, Fire PASS, Chemical HazCom) with color-coded active/expiring indicators.

Page F-7: Offline Cache & Sync Manager

/worker/offline

One-click "Download Today's Shift Modules" button (~25 MB total) and queue status for offline quiz results waiting to sync.

3. Backend Pages Breakdown (Supervisor & Admin Facing)

💻 BACK-END PAGES: SUPERVISOR & ADMIN PORTAL

Page B-1: Admin & Supervisor Secure Login

/admin/login

Enterprise credentials with Two-Factor Authentication (2FA) and automatic role routing to Supervisor or Admin dashboards.

Page B-2: Supervisor Crew & Shift Dashboard

/supervisor/dashboard

Real-time shift roster showing total crew count, certified workers, and pending training alerts before shift kickoff.

Page B-3: Supervisor "Toolbox Talk" Group Mode

/supervisor/toolbox

Fullscreen tablet player to stream the morning safety drill to an assembled 15–30 person crew with 1-click bulk attendance confirmation.

Page B-4: Supervisor Practical On-the-Job Verification

/supervisor/practical

Hands-on 30-second observation checklist with digital supervisor signature capture to confirm physical competency.

Page B-5: EHS Safety & Compliance Matrix Dashboard

/admin/compliance

Plant-wide heatmap matrix showing training completion by plant location, department, and shift, with critical safety violation alerts.

Page B-6: Course, Video & Visual Quiz Builder

/admin/builder

No-code authoring editor to upload videos, link multilingual audio tracks, and draw bounding boxes for "Spot the Hazard" coordinates.

Page B-7: Machine Asset & Printable QR Code Generator

/admin/assets

Equipment registry generating printable weatherproof QR stickers for shop-floor machinery.

Page B-8: Workforce Roster & Digital ID Badge Management

/admin/roster

Employee profiles and batch printer for wallet-sized employee ID cards with login QR codes.

Page B-9: Regulatory Compliance & One-Click Audit Export

/admin/audit

Generates 1-click OSHA-compliant PDF audit dossiers with timestamps and digital signatures, plus 30-day license expiration alerts.

Page B-10: System Settings & Integrations

/admin/settings

SMS/WhatsApp gateway configuration, offline cache limits, and external payroll webhooks.

4. Backend RESTful API Specification (Node.js & Express)

API Endpoint Method Role Description
/api/v1/auth/otp/send POST Public Sends 4-digit SMS / WhatsApp OTP to worker phone.
/api/v1/auth/otp/verify POST Public Validates OTP and issues session token.
/api/v1/auth/qr-login POST Public Authenticates worker directly via badge QR code.
/api/v1/modules GET Worker/Sup Lists assigned microlearning modules with multilingual audio.
/api/v1/modules/:id GET Worker/Sup Fetches single module details, video stream, and quizzes.
/api/v1/sync/completions POST Worker Receives batch of offline quiz completions and updates database.
/api/v1/supervisor/toolbox POST Supervisor Submits bulk attendance for morning group safety drill.
/api/v1/supervisor/practical POST Supervisor Records practical observation checklist and supervisor signature.
/api/v1/admin/compliance-matrix GET Admin Aggregates compliance percentages by plant, shift, and department.
/api/v1/admin/assets/generate-qr POST Admin Generates printable QR sticker sheets for equipment.
/api/v1/admin/reports/audit-pdf GET Admin Generates legally verifiable OSHA compliance PDF audit dossier.
